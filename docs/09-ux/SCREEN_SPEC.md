# Screen Specification

## Command Center
Purpose: understand current consumer advocacy workload.
Must show:
- money at risk
- action required
- active cases
- proactive findings
- recent resolutions

## New Case
Modes:
- upload
- describe problem
- select category

## Investigation
Show:
- timeline
- evidence
- policy
- eligibility
- uncertainty

## Strategy
Show:
- recommended strategy
- alternatives
- risks
- requested outcome

## Claim Review
Show exact submitted fields and evidence.

## Permission
Show:
- action
- target
- amount
- why
- policy
- allowed/denied
- approval control

## Agent Console
Show capability discovery and execution state.

## Monitoring
Show provider state, next check, requested information and follow-up action.

## Settings
Show autonomy, integrations, data controls and account.
