# Trust Patterns

## Show evidence
Every important finding can reveal the source.

## Show intended action
Approval UI states exactly what will be submitted.

## Show permission basis
Explain whether action is automatic or requires approval.

## Show execution
Display tool/capability execution in a human-readable stream.

## Show verification
Show the provider state that confirms the result.

## Show uncertainty
Use “potentially,” “needs review,” or “missing information” instead of false certainty.
