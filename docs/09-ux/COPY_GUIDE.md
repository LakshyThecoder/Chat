# Product Copy Guide

## Tone
Confident, calm, specific, transparent.

Prefer:
“€183.40 potentially recoverable”
over:
“Congratulations! AI found money!”

Prefer:
“Approval required because this action exceeds your €100 automatic limit.”
over:
“Oops! We need permission.”

Avoid:
- hype
- fake certainty
- “AI magic”
- unsupported promises
