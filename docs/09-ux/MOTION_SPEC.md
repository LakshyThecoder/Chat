# Motion Specification

## Principles
Motion communicates causality.

## Required sequences
- Evidence upload → processing → evidence accepted.
- Case discovery → case card appears.
- Claim proposal → approval state.
- Approval → executing.
- Tool execution → provider confirmation.
- Confirmation → resolved state.

## Avoid
- fake typing for everything
- arbitrary spinning
- animation that delays interaction
- motion as a substitute for information
