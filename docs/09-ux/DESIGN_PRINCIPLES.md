# Design Principles

## 1. Outcome first
Show what matters: amount, status, evidence, next action.

## 2. Trust through inspectability
Every important conclusion can be inspected.

## 3. Human control
Approvals explain the action and consequences.

## 4. Observable agent
The user can see what the agent is doing without being exposed to developer noise.

## 5. Calm premium aesthetic
Precise typography, disciplined spacing, restrained color, meaningful motion.
