# Definition of Done

A feature is complete only when all applicable items are true:

## Product
- User outcome is clear.
- Acceptance criteria are met.
- UX states are designed.

## Engineering
- Types compile.
- Lint is clean.
- Tests exist.
- Errors are handled.
- Observability exists.

## AI
- Schema validated.
- Prompt/version recorded where applicable.
- Untrusted content isolated.
- Deterministic guardrail present if consequential.

## WebMCP
- Tool schema defined.
- Side-effect class defined.
- Provider state behavior implemented.
- Verification exists.
- Idempotency exists for mutations.

## Security
- Authz checked.
- Permission checked.
- No secret exposure.
- Audit event emitted.

## Release
- Build passes.
- Environment variables documented.
- Demo behavior tested in supported environment.
