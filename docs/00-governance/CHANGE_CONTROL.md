# Change Control

## Small change
Implementation detail only; no contract change.
Update code/tests.

## Medium change
Changes a local interface or behavior.
Update interface + tests + affected docs.

## Large change
Changes architecture, domain state, security, AI trust boundary, WebMCP protocol usage, or product promise.
Create an ADR first; then implement.

## Forbidden
Do not silently change requirements because implementation is inconvenient.
