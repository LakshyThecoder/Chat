# Competitive Positioning

## Chat assistants
Strength: reasoning and drafting.
Aegis differentiator: persistent cases + evidence + permissioned execution + provider capabilities + verification.

## Browser automation
Strength: broad UI coverage.
Aegis differentiator: explicit agent-native capabilities instead of visual guessing.

Strength: category-specific workflows.
Aegis differentiator: general orchestration layer that can work across provider capability ecosystems.

## Personal finance tools
Strength: transaction visibility.
Aegis differentiator: converts insight into action and tracks the resolution.
