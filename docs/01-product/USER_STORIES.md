# User Stories

US-001 — Upload evidence
As a consumer, I can upload a receipt, invoice, email export, screenshot or document to start a case.

US-002 — Understand
I can see a concise reconstruction of what happened.

US-003 — Evidence
I can inspect the facts Aegis extracted and where each fact came from.

US-004 — Eligibility
I can see why Aegis thinks an action may be available.

US-005 — Strategy
I can compare recommended resolution strategies.

US-006 — Review
I can see exactly what the agent intends to submit.

US-007 — Permission
I can define when Aegis may act automatically.

US-008 — Execute
Aegis can execute an approved provider action through WebMCP.

US-009 — Verify
Aegis shows the provider state change that proves execution succeeded.

US-010 — Monitor
Aegis continues to monitor a submitted case.

US-011 — Follow up
Aegis can recommend or perform an appropriate follow-up after permission.

US-012 — Proactive
Aegis can surface actionable consumer issues from authorized data.
