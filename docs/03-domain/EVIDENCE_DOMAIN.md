# Evidence Domain

## Evidence types
- document
- transaction
- email
- screenshot
- provider record
- user statement
- policy reference

## Provenance
Every important fact should include:
- source ID
- source type
- extraction method
- confidence
- verification state
- time

## Fact lifecycle
RAW → EXTRACTED → NORMALIZED → VALIDATED → VERIFIED/UNVERIFIED.

## Rule
An unverified model-generated fact cannot silently become a verified fact.
