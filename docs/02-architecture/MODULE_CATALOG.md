# Module Catalog

## cases
Owns case identity and lifecycle.

## evidence
Owns document metadata, extracted facts, provenance and verification status.

## policies
Owns versioned provider policies and policy references.

## eligibility
Owns deterministic checks against case facts and policy rules.

## strategy
Owns resolution strategy proposals and ranking metadata.

## permissions
Owns autonomy policies and approval state.

## capabilities
Owns WebMCP/provider capability metadata.

## actions
Owns execution requests and action lifecycle.

## verification
Owns read-after-write provider verification.

## monitoring
Owns scheduled status checks and follow-up recommendations.

## audit
Owns append-oriented action/event history.
