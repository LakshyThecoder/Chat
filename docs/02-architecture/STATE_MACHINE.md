# Case State Machine

## States
DRAFT
INVESTIGATING
READY_FOR_REVIEW
AWAITING_APPROVAL
EXECUTING
SUBMITTED
UNDER_REVIEW
NEEDS_INFORMATION
RESOLVED
FAILED
CLOSED

## Allowed transitions
DRAFT → INVESTIGATING
INVESTIGATING → READY_FOR_REVIEW
READY_FOR_REVIEW → AWAITING_APPROVAL
READY_FOR_REVIEW → EXECUTING only if policy allows autonomous action
AWAITING_APPROVAL → EXECUTING
AWAITING_APPROVAL → READY_FOR_REVIEW
EXECUTING → SUBMITTED
EXECUTING → FAILED
SUBMITTED → UNDER_REVIEW
UNDER_REVIEW → NEEDS_INFORMATION
UNDER_REVIEW → RESOLVED
NEEDS_INFORMATION → UNDER_REVIEW
RESOLVED → CLOSED

Illegal transitions must fail closed.
