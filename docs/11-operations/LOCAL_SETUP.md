# Local Setup

## Steps
1. Install Node LTS.
2. Create Supabase project/local environment.
3. Copy .env.example to .env.local.
4. Set Regolo credentials.
5. Run migrations.
6. Seed provider fixtures.
7. Start provider simulators.
8. Start Next.js.
9. Run unit/integration tests.
10. Run WebMCP browser smoke.
