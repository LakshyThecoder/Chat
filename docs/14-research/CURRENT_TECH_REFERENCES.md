# Current Technology References

## WebMCP
Official specification:
https://webmachinelearning.github.io/webmcp/

Chrome developer guidance:
https://developer.chrome.com/docs/ai/agents

The current specification published in August 2026 describes `document.modelContext`, including `registerTool()`, `getTools()`, `executeTool()`, and tool-change events.

## Regolo
Documentation:
https://docs.regolo.ai/

Regolo documents OpenAI-compatible APIs and a model catalog. Its catalog includes capability metadata such as reasoning, function calling and vision; exact models/prices/limits should be queried from current documentation before deployment.

## Supabase
RLS documentation:
https://supabase.com/docs/guides/database/postgres/row-level-security

Use RLS + grants as defense in depth. Service-role credentials remain server-only.
