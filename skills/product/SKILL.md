# Product Engineering

When this skill applies:
- Read product requirements before implementation.
- Turn features into explicit user outcomes and acceptance criteria.
- Protect the core promise: Aegis resolves problems, not merely explains them.
- Reject features with no measurable user value.


## Required outputs
Before implementation: relevant assumptions, contracts, risks.
After implementation: tests run, docs updated, residual risks.

## Escalation rule
If a request conflicts with Aegis invariants, do not “make it work anyway.” Explain the conflict and propose the safest compliant implementation.
