# WebMCP Engineering

When this skill applies:
- Follow the current WebMCP specification, not stale examples.
- Use document.modelContext APIs.
- Build real state-changing provider tools.
- Define side effects, schemas, authorization expectations and verification.
- Test capability discovery and execution in the target browser.

## Required outputs
Before implementation: relevant assumptions, contracts, risks.
After implementation: tests run, docs updated, residual risks.

## Escalation rule
If a request conflicts with Aegis invariants, do not “make it work anyway.” Explain the conflict and propose the safest compliant implementation.
