# Aegis Cursor Pack V3 — Ceiling Edition

This is the final pre-build context package.

It is intentionally designed as an engineering operating system for Aegis rather than a collection of notes. It defines product intent, architecture, contracts, trust boundaries, WebMCP behavior, AI behavior, data rules, UX states, test requirements, release gates, and Cursor workflows.

## Finality rule
Do not keep expanding documentation merely to feel productive. Once implementation begins, improvements should be made by:
1. discovering an implementation reality,
2. recording it as a decision or contract change,
3. updating the relevant specification,
4. adding/adjusting tests,
5. continuing the build.

## What “ceiling” means
This pack is the ceiling for pre-code specification completeness. It cannot guarantee production correctness before runtime testing. Runtime verification is part of the build.

## Core objective
Build a product that makes a judge think:
“This is genuinely useful, AI is necessary, WebMCP is central, the engineering is real, and the experience is polished enough to ship.”
